# 解析界面的守恆條件與符號驗證

已安裝 TensorFlow 後，在有 `utvc/` 的目錄執行：

```powershell
python -m utvc.interface --csv runs/interface/check.csv
python -m unittest discover -s tests -p test_interface.py -v
```

`utvc/interface.py` 接受 CFD、實驗重建或兩個神經子域在同一界面點的單側場值與梯度。這是獨立的界面算子；全板有效熱傳 PINN 使用體積平均場，不能將其網格中心當成液氣兩側的單側跡值。

## 一個移動界面點需要的資料

法向量 **n** 從液相指向氣相，曲率 κ = divₛ **n**，半徑 R 的球形液滴 κ = 2/R。**u**Γ 為界面移速，j > 0 代表蒸發，j < 0 代表凝結。導熱通量 **q** = −k ∇T 應取實際局部流體 k；均溫板面內等效 k 不能帶入此式。

| 殘差（期望為零） | 使用的物理量 |
| --- | --- |
| ρₗ(**u**ₗ − **u**Γ)·**n** − j 與 ρᵥ(**u**ᵥ − **u**Γ)·**n** − j | 兩側相對界面的質量通量，kg/(m² s) |
| (**T**ᵥ − **T**ₗ)**n** − j(**u**ᵥ − **u**ₗ) − σκ**n** + ∇ₛσ | 法向毛細壓差、質量通量造成的反沖，以及切向 Marangoni 剪應力，Pa；**T** = −p**I** + **τ** |
| (**q**ₗ − **q**ᵥ)·**n** − j hfg | 低馬赫數 Stefan 能量跳躍，W/m²；忽略界面儲能、動能差與黏性做功 |
| Tₗ − Tᵢ 與 Tᵥ − Tᵢ | 兩側同一界面溫度 Tᵢ(x,t)；若實驗顯示溫度跳躍，須用界面熱阻取代此閉合 |
| j − α [a_w pₛₐₜ(Tᵢ) − pᵥ,H₂O] √(M/(2πRTᵢ)) | 選用 Hertz–Knudsen 通量；pᵥ,H₂O 為水蒸氣絕對分壓，a_w 為水活性，α 為傳質調適係數。壓力表壓不適用 |
| ρₗ[cₗ(**u**ₗ − **u**Γ) − Dₗ∇cₗ]·**n** − J | 不揮發溶質由液相進入界面的通量，J > 0 為吸附，kg/(m² s) |
| DΓ/Dt + Γ divₛ **u**Γ − Dₛ ΔₛΓ − J | 吸附量 Γ 的移動曲面守恆，包含面積擴張 |
| J − [kₐ(ρₗcₗ)(Γₘₐₓ − Γ) − k𝑑Γ] | 可逆 Langmuir 吸附模型；僅在實測濃度、吸附時間與適用範圍內使用 |

曲率、界面移速、雙側導熱梯度和表面張力梯度由呼叫端提供。例如液面輪廓為 φ(x,t)=0，且 φ 朝氣相增加，可用 **n**=∇φ/|∇φ|、Vₙ=−∂ₜφ/|∇φ|。若量得 σ(Γ,T)，可由切向的 ∂σ/∂Γ ∇ₛΓ 與 ∂σ/∂T ∇ₛT 得到 ∇ₛσ。填充比只定義初始液量，無法決定局部曲率或輸運係數。以獨立熱、壓力、質傳量級呼叫 `interface_loss(residuals, scales)`，才能得到可比較的無因次 MSE。

## 如何從單元測試走向實驗

範例刻意製造兩組平面界面跡值，j = ±0.00015 kg/(m² s)，界面以 Vₙ = −j/ρₗ 移動，Tᵢ(t) = 333.15 + 0.04t K。指定氣側導熱通量與潛熱後，液側梯度依 Stefan 條件建立。吸附量依可逆吸附方程隨時間改變。CSV 在 1、5、10、30、60 s 分別回報每個殘差的原單位、界面位置和溫度。測試另將熱通量故意改變 125 W/m²，驗證能量殘差與可反向傳播的梯度，也檢驗曲率壓差與 Marangoni 力的方向。

此案例驗證的是移動界面局部跳躍條件的程式與符號。真實氣泡預測還需要兩側 bulk PDE、界面演化、成核與接觸線資料。將兩個子網路在已知或重建的界面上分別取極限，輸入量測的壓力、濃度與局部熱物性，計算各殘差；配合液體和氣體各自的體積守恆方程才可能估計局部熱邊界層厚度。對於含不凝氣體的樣品，額外的氣相混合物傳質模型與水蒸氣分壓量測不可或缺。
