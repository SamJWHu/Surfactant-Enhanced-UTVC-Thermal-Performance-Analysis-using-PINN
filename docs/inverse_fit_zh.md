# 以均溫板壁溫辨識有效熱參數

這個工具利用獨立的有限體積模型反算兩個熱參數，可直接用於後續 PINN 訓練。純水步階試驗先同時辨識面內有效導熱係數 `k_xy`（W/m/K）與鰭片端面等效對流係數 `h_side`（W/m²/K）。各配方只估其 `k_xy`，沿用純水確定的散熱治具係數。溫度資料所辨識的是整塊均溫板的宏觀係數，其有效範圍包含建模時的厚度、填充率、工作溫度與負載。

## 在 Windows 11 先跑合成資料示範

在已安裝套件的專案目錄執行以下指令。

```powershell
python -m utvc.fit --demo --out runs/fit-demo --shape 16 8 3 --dt 0.5
```

示範採兩個刻意指定的導熱係數、同一組冷端係數與 0.08 K 的高斯雜訊來產生輸入。80 W 的整段試驗用於擬合，150 W 另一整段試驗留出驗證。示範水的設定值是 2400 W/(m K)，PEG 案例設定為 1900 W/(m K)，共同治具設定為 36,000 W/(m² K)。此測試確認反算與資料流可恢復已知值。因資料與擬合使用相同熱模型及網格，留出誤差不能外推到實際產品。

## 使用實測數據

將一次恆功率步階試驗編為一個 `run_id`。同一試驗的每個時間點填寫一列，整段使用同一個 `split`。CSV 欄位如下，編碼可採 UTF-8 或 Excel 的 CSV UTF-8。

| 欄位 | 單位或可用值 | 量測定義 |
| --- | --- | --- |
| run_id、split | 唯一實驗識別碼，fit / holdout | 每個配方至少各有一個擬合與一個盲測 run，同次物理試驗的不同時間點不能分開。 |
| case、load | 配方識別碼，80W / 150W | 兩種總瓦數分別對應 CPU/GPU 30/50 與 35/115 W。先核實加熱面實際輸入功率。 |
| fill、ambient_C | 0–1 之間的液體填充率，°C | 每次啟動前達熱平衡，記錄進氣溫度。相同配方在不同填充率應分開擬合，水對照與候選的治具及風扇條件應一致。 |
| time_s | s | 自施加完整功率算起的正時間。至少涵蓋早期升溫與接近穩定的區段。 |
| cpu_wall_mean_C、gpu_wall_mean_C | °C | 各晶片接觸區、均溫板外壁的面積平均。可用熱像或多點校正重建，單點熱偶與晶片接面感測器有不同觀測算子。 |
| sigma_T_K | K | 兩個面積平均的代表性量測標準差，此版假設兩測點相同。系統誤差另計。 |

`runs/fit-demo/synthetic_measurements.csv` 示範完整排版。以自己的實驗匯出同欄位 CSV 後執行以下指令。

```powershell
python -m utvc.fit --data measurements.csv --out runs/fit-real
```

若治具尺寸、已知厚度方向導熱係數或銅殼尺寸不同，可用 `--design design.json` 傳入固定 SI 參數，例如 `{"L":0.064,"W":0.024,"H":0.0016,"k_z":80.0}`。其他已知的配方參數可用 `--fixed-properties calibration.csv`，其中供估計的案例應留空 `k_xy`。保持兩個輸入設定隨輸出檔一起存檔，特別是固定的 `k_z` 和有效體積熱容。當這些輸入有不確定性，應改用其量測上下界重新擬合。

## 讀取及套用結果

- `wall_predictions.csv` 逐試驗並列實測與有限體積預測值。重點檢查留出工況的早期誤差、兩個熱源的偏差方向及最大絕對誤差。
- `fit_report.json` 記錄各配方的擬合及留出 RMSE、CPU/GPU 偏差、參數邊界、加權對數敏感度矩陣奇異值、網格、時間步與輸入檔指紋。各配方參數的不確定性診斷以已固定的治具係數為條件，治具本身的誤差與實驗間相關性未包含在此局部估計內。
- `identifiable_local` 是數值可辨識性檢查。它要求優化成功、沒有碰到參數搜尋邊界、敏感度矩陣滿秩，條件數小於 1,000，且最不敏感方向的局部對數標準差小於 1。這些是診斷門檻，工程允收規格應由專案指定。候選配方另列 `fixture_identifiable_local`。
- `effective_k_fit.csv` 可作為 PINN 的 `--calibration` 輸入，`fixture_design.json` 可作為 `--design` 輸入。後續模擬的填充率須與對應 run 相符。例如下列指令。

```powershell
python -m utvc train --case water --load 80W --calibration runs/fit-real/effective_k_fit.csv --design runs/fit-real/fixture_design.json --out runs/water-fit
```

若純水的兩個參數高度相關，增加早期與晚期觀測、冷凝端測點或獨立測定鰭片端 UA 再擬合。另做相同 `--data`、兩倍空間解析度及半時間步的反算，並比較留出殘差及估得的參數。多個物理樣機可按樣機或批次另外留出，同一樣機的 80/150 W 跨負載盲測主要查驗功率轉移，無法量化換批變異。
